\chapter*{ABSTRACT}
\addcontentsline{toc}{chapter}{ABSTRACT}
The MedCare Pro - Pharmacy Management System is a web-based application developed to improve the management of retail pharmacy operations. The system allows pharmacists to track real-time inventory, manage supplier relations, and process sales efficiently. It helps reduce manual errors and ensures patient safety by providing automated alerts for low stock levels and medicines approaching their expiration dates. The application includes secure access for administrators to manage the database and generate reports. The system is developed using Flask for the backend and MySQL for the database. By providing automated tracking and secure data management, the system simplifies the overall pharmacy management process.

\chapter{INTRODUCTION}

\section{BACKGROUND}
Pharmacy management involves the complex task of tracking thousands of unique medicine batches, each with its own expiry date and stock level. Managing this manually often leads to stockouts, financial losses due to expired goods, and potential risks to patient safety. The MedCare Pro system addresses these issues by digitalizing the inventory and sales process, making it much more efficient and reliable.

\section{SCOPE}
The system encompasses a web application with interfaces for:
\begin{itemize}
    \item \textbf{Inventory Management:} Tracking stock, batches, and expiry dates.
    \item \textbf{Sales \& Billing:} Processing transactions and updating stock in real-time.
    \item \textbf{Supplier Management:} Managing vendor contacts and supply history.
\end{itemize}

\section{OBJECTIVES}
\begin{itemize}
    \item To provide real-time inventory tracking.
    \item To automate expiry and low-stock alerts.
    \item To simplify the billing process for customers.
    \item To develop a secure and user-friendly web application.
\end{itemize}

\section{PROPOSED SYSTEM}
The proposed system is a Flask-based web application that centralizes all pharmacy data into a MySQL database. It features a responsive UI, secure authentication, and a global alert system that keeps the pharmacist informed of critical inventory states at all times.

\chapter{SRS (Software Requirements Specification)}

\section{PRODUCT OVERVIEW}
MedCare Pro is an all-in-one solution for small to medium-sized pharmacies. It allows users to register medicines, record purchases from suppliers, and generate sales invoices.

\section{PRODUCT FUNCTIONALITY}
\begin{itemize}
    \item \textbf{Admin:} Manages users, medicines, suppliers, and views reports.
    \item \textbf{Inventory:} Automated calculation of stock totals across batches.
    \item \textbf{Sales:} Deduction of stock and profit calculation per unit.
\end{itemize}

\section{HARDWARE REQUIREMENTS}
\begin{itemize}
    \item \textbf{Processor:} 2 GHz minimum, multi-core processor.
    \item \textbf{RAM:} 4GB or more.
    \item \textbf{Storage:} 500MB free space.
\end{itemize}

\section{SOFTWARE REQUIREMENTS}
\begin{itemize}
    \item \textbf{Operating System:} Windows/Linux/macOS for development.
    \item \textbf{Backend:} Python 3.x (Flask Framework).
    \item \textbf{Database:} MySQL Database.
    \item \textbf{Frontend:} HTML5, CSS3, JavaScript (AJAX).
\end{itemize}

\chapter{MATERIALS AND METHODS}

\section{DESIGN PHASE}
The system follows a relational design. The key entities include Users, Medicines, Suppliers, and Sales. The relationships are structured to ensure data integrity, such as preventing the deletion of a supplier if they are linked to active medicine batches.

\section{DATABASE DESIGN}
The database \texttt{LOGIN\_1} consists of:
\begin{itemize}
    \item \textbf{users}: Authentication and profile data.
    \item \textbf{medicine}: Central inventory with fields for batch, expiry, and pricing.
    \item \textbf{suppliers}: Vendor contact information.
    \item \textbf{sales}: Transaction logs with profit tracking.
    \item \textbf{purchases}: Logs all restock transactions to track costs.
\end{itemize}

\chapter{IMPLEMENTATION}
Implementation is realized using the \textbf{Flask} framework for the backend and \textbf{MySQL} for storage. The system uses Werkzeug for secure password hashing. A key implementation detail is the \texttt{context\_processor} which runs on every request to fetch alert counts for the navigation bar, ensuring the user is always aware of expiring items. The frontend utilizes AJAX requests to dynamically fetch existing medicine details by name, accelerating the data entry process.

\chapter{RESULTS AND DISCUSSIONS}
The system successfully manages inventory and processes sales. The front end provides a clean interface for adding medicines and searching through the stock. The backend handles complex queries to aggregate stock levels and identify medicines nearing expiry. The automated alert system operates correctly, immediately notifying users of critical thresholds without requiring manual checks.

\chapter{CONCLUSION}
The MedCare Pro system is a robust tool for pharmacy management. It improves efficiency, reduces waste by tracking expiry dates, and provides clear financial insights through sales reporting. By digitizing manual processes, the system allows pharmacists to focus more on patient care. Future updates could include barcode scanning for faster checkout, automated reordering emails to suppliers, and a dedicated mobile application.
